# Behavior structure

Compare occurrence frequency, cumulative dependence and per-occurrence strength for all six behaviors and all 15 behavior pairs per model.

## Interpretation

Behavioral support order counts distinct behavior classes. It does not count players or vehicles. The frequency figure uses allocated BO1 mass shares. Supplementary S2b instead uses pre-allocation BO1, BO2 and higher-order dividend masses at K=6 with uniform weights and lambda=0 or 0.25; see [Robustness](../03_robustness/tables.md). Those denominators must remain separate.

## Readable tables

[Open selected tables](tables.md). This page includes:

- Frequency and cumulative contribution

Results are precomputed aggregate statistics displayed as Markdown tables and existing figures. This repository contains no CSV exports or per-scene result files.
