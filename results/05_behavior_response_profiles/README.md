# Behavior response profiles

Selected tables show spatial and temporal absolute response profiles for all six behaviors and the stationary-behavior breakdown across physical tiers.

## Interpretation

Overall behavior summaries average tiers within each scene before averaging scenes. A response profile describes sensitivity of the model output to context replacement. Its magnitude is not ground-truth future risk. The displayed stationary-tier table is a selected view of the broader supplementary profiles.
