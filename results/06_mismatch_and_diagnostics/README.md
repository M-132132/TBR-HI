# Mismatch and diagnostics

Selected extensions show conditional high-set correspondence, quadrant agreement and response-to-risk scale diagnostics.

## Interpretation

The high-set null preserves scene-level marginal set sizes. Its archived table retains rounded effects and p-value bounds. The BO2 high-set cohort additionally requires valid future-risk information. Scale ratios use a declared denominator floor and are descriptive summaries.

## Readable tables

[Open selected tables](tables.md). This page includes:

- Conditional high-set correspondence
- Quadrant agreement
- Response-to-risk scale

Results are precomputed aggregate statistics displayed as Markdown tables and existing figures. This repository contains no CSV exports or per-scene result files.
