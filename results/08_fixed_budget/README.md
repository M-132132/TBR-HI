# Fixed-budget analysis

The BO1 extension covers Top-100/300/500 point estimates, paired precision increments, alternative tie policies and EMP-M size-standardized/singleton-only sensitivities.

## Interpretation

The endpoint is ground-truth future clearance below 1 m. Paired effects retain the original nine-test BH family. Tie-randomization intervals describe alternative tie orderings and differ from scene-bootstrap confidence intervals. Size-standardized and singleton-only tables are EMP-M only, at archived display precision. This candidate-review extension has a different target from response localization.

## Readable tables

[Open selected tables](tables.md). This page includes:

- Random tie-policy sensitivity
- EMP-M size-standardized sensitivity

Results are precomputed aggregate statistics displayed as Markdown tables and existing figures. This repository contains no CSV exports or per-scene result files.
